# Week 0 — HTML & CSS Basics

This is the starting point. Before writing any JavaScript or building servers, we first got comfortable with the building blocks of every webpage.

## What we learned

- **HTML** — How to structure a webpage using tags like headings, paragraphs, links, images, and forms.
- **CSS** — How to style and lay out HTML elements: colors, fonts, margins, padding, and basic layout.

## Files

| File | What it does |
|------|-------------|
| `index.html` | A simple HTML page showing how to structure content |
| `index.css` | CSS styles applied to that page |

## Key idea

Every website you see is just HTML (the skeleton), CSS (the skin), and JavaScript (the muscles). This week is about the skeleton and skin.
