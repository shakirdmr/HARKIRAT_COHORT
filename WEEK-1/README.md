# Week 1 — JavaScript Fundamentals

This week covers the core building blocks of JavaScript — the things you use every single day as a developer.

## What we learned

- **Variables** — storing values with `let`, `const`, and `var`
- **Arrays** — lists of items and how to loop through / access them
- **Functions** — reusable blocks of code (regular, arrow, and expression styles)
- **Callbacks** — passing functions as arguments to other functions
- **setTimeout** — running code after a delay (intro to async thinking)
- **Parsing** — converting strings or JSON into usable data

## Key idea

JavaScript runs line by line, but `setTimeout` lets us schedule code for later. Callbacks are how we say "when you're done with X, do Y" — this is the foundation of all async programming.
